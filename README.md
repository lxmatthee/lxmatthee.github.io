## Google Scholar notes
- A public webpage and PDF do **not** guarantee Google Scholar inclusion or citation extraction.
- Google's scholarly indexing guidance recommends crawlable HTML abstract pages with citation metadata and direct PDF links. Keep one publication per HTML page.
- The 5 MB limit is Google's published guidance for PDF indexing, but reducing file size alone cannot force citations to be counted.
- GitHub Pages may or may not be crawled and indexed by Google Scholar. An established academic repository can be more reliable.
- Check `Cited by` on papers cited by each thesis, not just the thesis entry itself.
- Do not add a new DOI or change the thesis's official bibliographic identity.

Official guidelines: https://scholar.google.com/intl/en/scholar/inclusion.html
